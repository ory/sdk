# KeyState

Only a \"confirmed\" key can be used to authenticate. A \"locked\" key was disabled after too many wrong-PIN attempts; rotating its pin_secret unlocks it.

## Enum

* `INITIAL` (value: `'initial'`)

* `CONFIRMED` (value: `'confirmed'`)

* `LOCKED` (value: `'locked'`)
